# Summer TV

面向 Android TV / 电视盒子的播放器定制版，基于开源 TVBox 项目改版，主打遥控器友好的大屏体验。

本项目为个人定制版本，通过旁加载方式小范围分发，不在任何应用商店上架。

## 能力

- 电视端界面，适合遥控器操作
- 点播、直播、收藏、历史记录
- 固定使用内置配置；应用不再提供设置页，点首页左上角的 Summer TV 标志进入「关于」
- 搜索结果与线路按本机播放记录排序，播放失败时自动换线路、换同名站点
- 应用内更新检查

## 内容声明

本项目仅提供播放器、播放控制和配置管理能力，不提供影视内容的生产、存储、上传、转码或分发服务。

**本版本内置了默认配置**，包括约 32 个第三方点播站点接口、2 个解析接口，以及约 220 个频道、250 余条公开直播源地址（含 3 条经逐条测试后新增的境外官方频道源，测试记录见运维仓库 `docs/live-sources-report.md`）。这些接口与地址均指向第三方服务，本项目既不运营也不控制它们，不对其内容、可用性与合法性作任何保证或背书。

用户应自行确认所使用配置、直播地址和内容源的合法性，并自行承担对应使用责任。当前版本已移除设置页，不提供「配置地址」与「直播地址」入口，固定使用内置配置；介意内置配置者请勿安装本版本。

默认配置中还包含一个指向第三方 CDN 的爬虫 jar 地址，运行时会被下载并加载执行。这是 TVBox 生态的通用机制，但意味着该第三方地址的控制者能够在设备上执行代码。应用不提供更换入口，介意者请勿安装本版本。

## 隐私说明

### 不做的事

本项目不接入任何第三方广告 SDK、统计 SDK、支付 SDK 或推送 SDK，不申请 Advertising ID 权限，不读取通讯录、定位、短信、通话记录或硬件序列号。

### 会做的事

**自建远程配置与统计**：本应用内置了自行实现（非第三方 SDK）的远程商业配置、广告位与匿名统计能力。

- 统计**默认开启**，「关于」页统计开关下方有一行说明，你可以随时在「关于 → 匿名统计」中关闭。关闭后不采集、不入队、不上报，服务端配置无法绕过这一点，关闭时会立即清空尚未发送的队列。
- 启用后采集的事件包括：应用启动、页面浏览、播放开始/成功/失败、广告请求/展示/点击
- 随事件上报的字段仅限：应用版本、渠道、设备类型、播放场景（点播或直播），以及一个应用首次运行时随机生成的标识符（不是硬件序列号，卸载重装即重置）
- 上报前会过滤掉键名包含 url、source、keyword、query 的字段，不上传片源地址、配置地址或搜索词原文

**豆瓣公开接口**：首页「今日精选」和默认海报墙会请求豆瓣公开接口（movie.douban.com、m.douban.com），获取近期热播榜单、简介和海报。请求不携带账号或设备标识，只带普通浏览器 User-Agent；榜单按天缓存在本机。

**本机播放质量统计**：为了把能播、起播快的站点和线路排在前面，应用会在本机记录各站点 / 线路的起播成功次数、失败次数和起播耗时（按 30 天半衰期衰减）。这些数据只保存在本机，不随统计上报，也不上传到任何服务器。

**本机数据**：配置地址、播放偏好、历史记录、收藏记录与缓存文件保存在本机，不会由应用主动上传。崩溃时会在本机 `filesDir/crash/` 保存堆栈日志，仅供本地排查，不会自动上传。可通过系统应用管理清理。

**第三方服务**：用户自行添加或默认配置中的第三方接口如包含网络请求、日志、统计或鉴权行为，其数据处理规则由对应服务决定，不属于本项目控制范围。

## 应用内更新

本应用不在应用商店分发，因此内置了更新检查：进入首页时（每次启动最多提示一次）或在「关于 → 检查更新」中，读取本仓库 GitHub Releases 最新版本里的 `update.json`，按设备对应的构建变体挑选安装包；下载后校验 SHA-256，并在安装前比对下载包与已安装应用的签名证书，全部通过才唤起安装。Android 8.0 起需要允许 Summer TV「安装未知应用」，应用会引导你到系统设置开启。

发布新版本：运行 `tools/release.ps1 -Version <版本号> -ReleaseNote "更新说明"`（运维仓库），把产物目录里的 APK 与 `update.json` 原名上传到标签为 `v<版本号>` 的 Release，并设为 Latest。

## 发布包说明

公开分发 APK 使用固定 release 签名构建。请不要使用调试签名或临时签名发布，否则后续版本无法稳定覆盖升级。构建时若未提供签名配置，release 构建会直接失败而不会产出未签名包。
